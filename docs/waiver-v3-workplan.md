# Waiver decision support v3

Implementation requested 2026-09-15. This is a development checklist, not a claim of completion.

- [ ] Refresh propagation, explicit readiness reasons, score explanations.
- [ ] Injury return scenarios, legal weekly lineup comparisons, hold versus replace.
- [ ] This week / four-week bridge / rest-of-season plans with alternatives and deadlines.
- [ ] Current-season opportunity evidence, missing-data flags, source timestamps.
- [ ] Verified league rules and budget, conservative bid ranges, no invented market odds.
- [ ] Immutable decision inputs, retrospective outcome scoring, ESPN/hold baselines.
- [ ] Regression tests including Brown/Pierce, mobile browser verification.
- [ ] Safe migration, deployment, source refresh, release documentation and user checklist.

Boundaries: no ESPN transactions, no credential rotation, no paid feed, no medical return predictions. Unknown data remains unknown. Future scenario totals are planning comparisons, not calibrated forecasts. Existing automated tests do not establish fantasy performance.
