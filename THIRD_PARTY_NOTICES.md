# Third-party notices

Fantasy Command Center uses or integrates with:

- Cloudflare Workers and D1 for application hosting and persistence.
- ESPN Fantasy's user-authenticated web APIs for the user's own league data. ESPN does not provide a public OAuth flow for this use case; the app is not affiliated with or endorsed by ESPN.
- nflverse data through `nflreadpy` for public NFL statistics and schedules. Review the licenses and attribution included with each nflverse dataset.
- Open-Meteo for game-time weather forecasts.
- Wrangler, pandas, PyArrow, and Requests under their respective open-source licenses.

The application does not republish full ESPN pages or third-party fantasy articles. Optional future AI/news features must summarize and link to sources rather than copying protected content.
